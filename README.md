# Skinstric

🔗 **Live Demo:** [skinstric-wandag.vercel.app](https://skinstric-wandag.vercel.app)

An AI-powered skincare analysis web application built with Next.js and TypeScript. Users enter their name and location, then upload or capture a photo which is analyzed by an AI to predict demographic information (race, age, gender) with confidence scores. Results are displayed on an interactive demographics dashboard where users can view and correct the AI's predictions.

## Tech Stack
- Next.js 16
- TypeScript
- React
- CSS Modules
- REST APIs

## Features
- Multi-step onboarding form with validation
- Camera capture using getUserMedia API
- Gallery image upload with base64 encoding
- Animated donut chart displaying AI confidence scores
- Interactive demographics dashboard
- Responsive design for desktop, tablet, and mobile

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the app.
